## Why

Some changes were made and documented by AI before starting to use openspec

## What Changes

Completed AI tasks in docs are converted to archived openspec changes (incl proposal, design, spec changes and tasks). 
Also, new specs are made based on those tasks and what's in ARCHITECTURE.md, DECISIONS.md, GLOSSARY.md, SECURITY.md and TESTING.md. Those files shouldn't be needed anymore afterwards. 
The only thing that should be left in docs are ai-tasks that aren't completed yet.
AGENTS.md, .github/copilot-instructions.md, and CONTRIBUTING.md guidance should reference OpenSpec specs and archived changes instead of docs pages for requirement discovery.
